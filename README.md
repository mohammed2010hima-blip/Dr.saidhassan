# 🎓 منصة د.سعيد حسن التعليمية

منصة تعليمية متكاملة لتدريس اللغة العربية، تتيح للمدرس إنشاء امتحانات تفاعلية بالذكاء الاصطناعي ومتابعة نتائج الطلاب.

## ✨ المميزات

- 📄 **رفع PDF وتحليله بالذكاء الاصطناعي** — يستخرج الأسئلة تلقائياً
- 📝 **نظام امتحانات متكامل** — MCQ ومقالي مع تصحيح تلقائي
- 👩‍🏫 **لوحة تحكم المدرس** — إدارة الاختبارات والكورسات والمجموعات
- 📊 **إحصائيات ونتائج** — متابعة أداء الطلاب بشكل مفصّل
- 🌙 **ثيمين** — بنفسجي وذهبي

## 🛠 التقنيات المستخدمة

- **Next.js 14** (App Router)
- **Prisma ORM** + SQLite
- **Supabase** (قاعدة البيانات السحابية)
- **Google Gemini AI** (تحليل PDF واستخراج الأسئلة)
- **Tailwind CSS**
- **TypeScript**

## 🚀 تشغيل المشروع محلياً

### 1. تثبيت المكتبات
```bash
npm install
```

### 2. إعداد ملف البيئة
```bash
cp .env.example .env
```
ثم افتح `.env` وأضف مفاتيحك الحقيقية.

### 3. إنشاء قاعدة البيانات
```bash
npm run db:push
node prisma/seed.js
```

### 4. تشغيل السيرفر
```bash
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)
